# 🍕 Pizza Hut SQL Project

End-to-end SQL project analyzing Pizza Hut sales data to extract key business insights such as revenue trends, best-selling products, category performance, and customer ordering patterns.

---

## 📌 Project Overview
This project focuses on analyzing Pizza Hut sales data using SQL. The goal is to derive meaningful insights that can help improve business decisions, increase revenue, and understand customer behavior.

---

## 📊 Dataset Description
The dataset includes multiple tables:
- **orders** – order date and time
- **order_details** – quantity of pizzas ordered
- **pizzas** – price and size details
- **pizza_types** – category and pizza names

---

## 🛠️ SQL Concepts Used
- Joins (INNER JOIN)
- Aggregations (SUM, COUNT, AVG)
- GROUP BY & HAVING
- Subqueries
- Window Functions (RANK, DENSE_RANK)
- CTE (Common Table Expressions)

---

## 🔍 Key Business Insights
- Identified top-selling pizzas based on quantity and revenue
- Analyzed revenue trends over time
- Found most popular pizza categories
- Evaluated customer ordering patterns
- Determined peak order hours
